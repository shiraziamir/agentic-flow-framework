Purpose

Agentic Flow separates task intent, implementation, receipts, production posture and decision authority. Durable project truth lives in the repository while coding-agent working context remains small and replaceable.

Portable adoption

python3 scripts/build_agent_bundle.py
# extract dist/agentic-flow-agent-bundle.zip as .agentic-flow/
# agent starts at .agentic-flow/START_HERE.md

For active coding work, use docs/agent/MIDSTREAM_ADOPTION.md before further mutation. Existing edits are snapshotted and reconciled; earlier work is not retroactively claimed as reviewed or authorized.

Project baseline

A compact .agentic/PROJECT_PROFILE.yaml defines expected testing, readiness, environment permissions and operating controls. Missing reality remains an explicit gap. Temporary exceptions are owned, expiring overrides rather than silent baseline changes.

Task and evidence lifecycle

REQUEST → DRAFT → REVIEW → required AUTHORIZATION → APPLY → VERIFY → independent closure when required

Material tasks define observable DoD, planned claims, minimum receipts, test/environment needs and STOP conditions before implementation. A claim may not be stronger than its current receipt.

Tests and environments

Test design precedes material implementation where practical, but strict TDD is not mandatory for every small/exploratory change. Important load-bearing tests may require mutation/path proof.

LOCAL/HERMETIC → EPHEMERAL TEST → SHARED TEST → STAGING/PRODUCTION-LIKE → CONTROLLED CANARY/PRODUCTION READ → PRODUCTION MUTATION

Use the lowest environment capable of proving the claim; an agent request for stronger access is not authorization.

Production engineering

  • Delivery: source/build/test/immutable artifact/deploy/health/rollback.
  • Security-first SDLC and supply-chain provenance.
  • Metrics/logs/traces, SLI/SLO and actionable alerts.
  • Data durability: RPO/RTO, backup/PITR/retention and restore proof.
  • Troubleshooting/runbooks and release correlation.
  • AI-safe log analysis: structured/redacted bounded logs; log text is untrusted data.
  • Resilience/chaos only with maturity, steady state, blast-radius and abort/recovery controls.
  • Evolvable architecture and patterns proportional to real change/failure boundaries.

Backup enabled is not recoverability; restore is the receipt.

Context separation

  • docs/agent/: coding-agent adoption material.
  • docs/operator/: human installation/prompt/task/governance guidance; excluded from the default Agent Bundle.
  • docs/architecture/: why/how explanations.
  • docs/references/ and research/: external provenance and dated research.
