Surface verification

FRONTEND: browser/user-visible behavior, interaction path, console/network errors, loading/error/empty/permission states, real client contract. Screenshot alone is not a flow receipt.

BACKEND: real handler/service/repository boundary, validation/authz/error paths, retry/idempotency/provider/persistence. HTTP success alone is not a persistence receipt.

SHARED: mechanically identify affected consumers; producer tests alone do not prove consumer compatibility.

DATA: representative existing data, migration/write-read/constraints/partial failure/idempotency/rollback boundary.

INFRA/CI: exact target, plan/rendered diff, trigger conditions, permissions, artifact handoff and deployed artifact; preserve skipped/neutral checks.

SECURITY/AUTH: relevant negative/unauthorized/tenant/ownership paths and versioned standards scope.

RELIABILITY/PERFORMANCE: comparable baseline, repeated observations, cache/retry/timeout/concurrency/provider/log-query boundaries.

Blind-spot audit

For HIGH/evidence-complex work, a cold read-only audit looks for stale ref/environment, unexpected surface/consumer, bypassed changed path, weak proxy checks, hidden frontend/backend/data/infra/security/reliability gaps, and report wording broader than the verified universe.

Independent review

task/DoD/classification
→ actual diff/source
→ raw receipts
→ independent falsifying checks
→ executor narrative last

Reviewer output is JUDGMENT, not a substitute for runtime/persistence/deployment/security receipts.

Reality-reflecting reports

Reports preserve exact ref/artifact/environment, counts, PASS/FAIL/PARTIAL/SKIPPED/UNVERIFIED states, important checks not executed, unknowns and residual risk. Global language like “no regressions” requires a finite universe plus exhaustive method.

Deterministic lint

python3 scripts/verification_lint.py <task/evidence/report files>

This catches mechanical contradictions such as VERIFIED-without-evidence, missing evidence refs, stale head refs and global verified claims without exhaustive bounded evidence. It does not replace semantic project verification.

Context and history

Load only the current task/classification, selected verification profiles and triggered skills. Completed tasks, reports, evidence, judgments, usage, retrospectives and stories remain cold and on-demand.
