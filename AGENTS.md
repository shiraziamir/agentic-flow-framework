# Agent instructions for this repository

This repository is the authoritative home of Agentic Flow Framework. The old Google Drive folder is archival only.

## Read order

1. `README.md`
2. `agentic-flow-framework.en.md` for canonical framework content
3. Only the research/template file relevant to the task

Do not preload both HTML renderings unless the task is specifically about rendering or translation.

## Authority

- Canonical conceptual source: `agentic-flow-framework.en.md`.
- English/Persian HTML files are reader-facing synchronized renderings.
- `research/` stores source-grounded research notes, not independent policy.
- `templates/` are examples; they do not override the canonical framework.

## Update discipline

- Keep the root instruction file concise; do not turn this file into the framework manual.
- One concept should have one primary home. Link instead of duplicating large passages.
- For material framework changes, use current primary sources and distinguish verified facts from recommendations.
- When canonical content changes materially, update both HTML renderings in the same change.
- Preserve RTL for Persian prose and LTR for code, commands, paths, identifiers, YAML, and URLs.
- Do not claim model/tool behavior from memory when current vendor documentation can verify it.
- Do not treat prompt caching as context compression unless a provider explicitly documents that behavior.
- Do not equate observed skill/model-route association with causality without a controlled comparison.

## Repository mutation

Keep changes scoped. Do not add generated build artifacts, raw agent transcripts, secrets, or large log dumps. Research receipts should be links plus concise findings, not copied vendor documentation.
