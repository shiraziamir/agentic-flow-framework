# controlled-agent-experiment

Use when claiming a model/skill/routing policy improves quality, cost, latency, or rework.

Freeze task fixture, tools, baseline, acceptance gates, and evidence collection. Change one variable only. Run isolated sessions. Measure quality, regressions, rework, latency and cost where available.

## Mutation authority
Experiment-specific only.

## Output
Control/treatment matrix, limitations, causal boundary, promotion recommendation.
