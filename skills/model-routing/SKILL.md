# model-routing

Use when model/delegation choice is material.

## Routing
- T0 deterministic for exact mechanical work.
- T1 cheap/read-only for discovery, inventory, log reduction, classification.
- T2 standard for bounded coding.
- T3 judgment for architecture, security, ambiguous root cause, public contracts, repeated failed loops, high-risk closure.

Prefer same-family cheaper models when empirically reliable, but do not assume quality from family membership.

## Escalate when
`UNKNOWN_ROOT_CAUSE`, `CROSS_MODULE_PUBLIC_CONTRACT_CHANGE`, `SECURITY_OR_AUTH_CHANGE`, `DATABASE_OR_DURABLE_DATA_CHANGE`, repeated failed loops, working-set expansion, conflicting evidence, or high-risk closure.

## Mutation authority
T1 default NONE; T2 only frozen scope; T3 judgment does not itself grant mutation.

## Output
tier, task split, selected model/config if known, escalation triggers, evidence handoff shape.
