# مستندات مخصوص Agent

این پوشه برای استفاده‌ی Lazy توسط Agent برنامه‌نویس طراحی شده است.

از `START_HERE.md` شروع کنید. اگر Coding از قبل در حال انجام است، `MIDSTREAM_ADOPTION.md` را استفاده کنید. `BUNDLE_USAGE.md` روش ساخت و استفاده از ZIP قابل‌حمل را توضیح می‌دهد. `ADOPTION_CHECKLIST.md` و `ADOPTION_RECEIPT_SCHEMA.md` فقط هنگام Adoption/Bootstrap لازم هستند.

Agent نباید مستندات Operator، Research، Judgmentهای تاریخی، Retrospectiveها یا Storyها را به‌صورت دائمی preload کند.
