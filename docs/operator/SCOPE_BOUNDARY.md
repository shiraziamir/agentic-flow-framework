# Operator Scope Boundary

Operator-facing guides explain use, examples and decision points. They do not override `ARCHITECTURE.md`, schemas, verification/production profiles, frozen task contracts or owner authorization.

Coding agents should receive only the agent-facing/canonical runtime subset through the bundle. If an operator guide contains a useful rule that must govern agents, promote that rule into the canonical architecture/schema/profile/skill first rather than asking agents to preload operator documentation.
