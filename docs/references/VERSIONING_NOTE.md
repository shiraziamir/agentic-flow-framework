# Source Freshness / Versioning Note

External vendor/product behavior can change faster than framework releases. `PRIMARY_SOURCES.md` records the sources used at the time of design, but model names, pricing, CLI behavior, API fields, standards versions and product defaults must be rechecked when materially relevant to a current task.

The framework therefore separates dated research/reference evidence from canonical policy and avoids making permanent agent instructions depend on transient vendor details unless they are explicitly version-bound.
