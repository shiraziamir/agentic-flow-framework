# Documentation Map

```text
ARCHITECTURE.md                 canonical policy
VERSION                         canonical release version
schemas/                        durable contracts
verification/                   task/change verification profiles
production/                     project production-readiness profiles
skills/                         lazy procedures
prompts/                        bootstrap/workflow/supervisor prompts
docs/agent/                     agent-facing adoption docs
docs/operator/                  human/operator-only docs
docs/architecture/              reader architecture explanations
docs/references/                consolidated external source index
research/                       dated research notes
scripts/                        deterministic helper/lint/bundle tools
templates/                      project examples
bundle/                         bundle usage/install helper files
```

A coding agent starts with `docs/agent/START_HERE.md`; an operator starts with `docs/operator/OPERATOR_GUIDE.en.md` or `.fa.md`. Neither path becomes a competing policy authority.
