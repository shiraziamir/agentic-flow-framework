# Portable Bundle Boundary

The portable Agent Bundle is a runtime/adoption subset of the framework, not the entire human documentation repository.

Included: canonical `ARCHITECTURE.md`/`VERSION`, schemas, verification profiles, production profiles, skills, bootstrap/workflow/supervisor prompts, templates, agent-facing docs and deterministic helper scripts.

Excluded by default: `docs/operator/`, `docs/references/`, `research/`, reader HTML/long-form explanatory views, retrospectives, stories and repository history.

Reason: operator education and external provenance remain available in the source repository but should not become permanent coding-agent context. When a task needs research/provenance, the agent may retrieve the relevant source through the normal research workflow.
