# Workflow prompt — BUILD PROJECT RETROSPECTIVE

```text
Build an evidence-grounded execution retrospective / work reconstruction report for the requested project or campaign.

Read only on demand:
1. ARCHITECTURE.md
2. skills/project-retrospective/SKILL.md
3. schemas/EXECUTION_RETROSPECTIVE_LEDGER.md
4. the relevant Git/task/evidence/judgment/token-history artifacts for the requested boundary

Do not preload unrelated completed-task history.

Requirements:
- establish the reliable reconstruction boundary first;
- use Git/durable artifacts as primary evidence;
- classify material facts as PROVEN, RECONSTRUCTED, or UNKNOWN;
- never manufacture historical iteration/time/token/provider numbers;
- reconstruct timeline, task/amendment/STOP/review flow, implementation and governance commits, tests, defects caught before closure, prevented false-complete states, mutations, deferred findings, governance overhead, and method evolution where evidence supports them;
- include token/cost/provider-call metrics only when trustworthy telemetry exists;
- explain where ceremony reduced real risk and where a lighter governance class would have been sufficient;
- include "What we would do differently next time";
- optionally produce a second public/portfolio/self-branding narrative, but every public claim must remain evidence-bounded;
- timestamp and version the report and cite/ref source artifacts.

Return the report path, evidence boundary, unknowns, and a concise metric summary.
```
